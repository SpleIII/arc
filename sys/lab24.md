### «Работа с файловой структурой ОС Linux»

**Цель работы:** Изучить команды для работы с файлами в ОС Linux, освоить создание, объединение, перемещение файлов, анализ и изменение прав доступа, а также получение информации о процессах и пользователях.

**Используемое оборудование и ПО:** Персональный компьютер, операционная система Linux (Ubuntu/Debian), терминал (bash).

---

### Ход выполнения работы

**1. Ознакомление с файловой структурой ОС LINUX и изучение команд работы с файлами**

Была изучена иерархическая структура каталогов Linux (команда `ls /`). Основные системные директории: `/home` (пользовательские данные), `/etc` (конфигурации), `/var` (логи), `/tmp` (временные файлы). Получена справка по базовым командам: `man ls`, `man cp`, `man mv`.

**2. Создание двух текстовых файлов**

С помощью команды `echo` и перенаправления потока вывода (`>`) были созданы два исходных текстовых файла:
```bash
echo "Текст первого файла" > 1.txt
echo "Содержимое второго файла" > 2.txt
```
*Результат:* Файлы `1.txt` и `2.txt` созданы в текущем каталоге.

**3. Объединение файлов и просмотр содержимого**

Создан объединённый файл. Операция выполнена командой `cat` с конкатенацией:
```bash
cat 1.txt 2.txt > 3.txt
cat 3.txt
```
*Результат:* Файл `3.txt` содержит последовательно текст из `1.txt` и `2.txt`. Содержимое выведено на экран.

**4. Создание новой директории и перемещение файлов**

Создан каталог `newdir`, куда были перемещены все три файла:
```bash
mkdir newdir
mv 1.txt 2.txt 3.txt newdir/
```
*Результат:* Файлы перемещены в папку `newdir`.

**5. Вывод полной информации о файлах и анализ уровней доступа**

В каталоге `newdir` выполнена команда:
```bash
ls -la
```
**Полученный результат (до изменений):**
```
-rw-rw-r-- 1 student student 29 May 7 11:12 1.txt
-rw-rw-r-- 1 student student 30 May 7 11:13 2.txt
-rw-rw-r-- 1 student student 59 May 7 11:13 3.txt
```

**Анализ уровней доступа:**
Строка прав `-rw-rw-r--` (код 664) расшифровывается так:
*   **Тип:** `-` (обычный файл).
*   **Владелец (student):** `rw-` — чтение и запись.
*   **Группа (student):** `rw-` — чтение и запись.
*   **Остальные:** `r--` — только чтение.
*   **Вывод:** Права на выполнение (`x`) отсутствуют у всех категорий пользователей.

**6. Добавление права выполнения для группы и остальных пользователей**

Для изменения прав использована команда:
```bash
chmod go+x 1.txt 2.txt 3.txt
```
Также для установки корректной маски `rwxrwxr-x` использовался числовой метод:
```bash
chmod 775 1.txt 2.txt 3.txt
```

**7. Просмотр атрибутов файлов после изменений**

Повторно выполнена команда `ls -la`:
```
-rwxrwxr-x 1 student student 29 May 7 11:12 1.txt
-rwxrwxr-x 1 student student 30 May 7 11:13 2.txt
-rwxrwxr-x 1 student student 59 May 7 11:13 3.txt
```

**Сравнительный анализ:**
| Файл | Права до (маска) | Права после (маска) | Изменения |
|:---|:---|:---|:---|
| `1.txt` | `-rw-rw-r--` (664) | `-rwxrwxr-x` (775) | Добавлено выполнение группе и остальным |
| `2.txt` | `-rw-rw-r--` (664) | `-rwxrwxr-x` (775) | Добавлено выполнение группе и остальным |
| `3.txt` | `-rw-rw-r--` (664) | `-rwxrwxr-x` (775) | Добавлено выполнение группе и остальным |

Теперь владелец и группа имеют полный доступ (чтение, запись, выполнение), а остальные пользователи — чтение и выполнение без права записи.

**8. Получение информации об активных процессах и именах других пользователей**

Выполнены команды:
```bash
# Список активных процессов
ps aux

# Пользователи, находящиеся в системе
who
```
*Результат:* Команда `ps aux` отобразила таблицу запущенных процессов всех пользователей (с указанием PID, использования CPU/MEM). Команда `who` показала, что в системе работает пользователь `student`, другие активные пользователи в данный момент отсутствуют.

### Ответы на контрольные вопросы

**1. Что считается файлами в ОС LINUX?**
В ОС Linux практически всё представлено в виде файлов. Помимо обычных текстовых и бинарных данных, к файлам относятся:
*   **Каталоги** — файлы, содержащие списки других файлов.
*   **Файлы устройств** — обеспечивают интерфейс для работы с оборудованием (находятся в `/dev`).
*   **Сокеты и именованные каналы (FIFO)** — для межпроцессного взаимодействия.
*   **Символические и жесткие ссылки** — файлы, указывающие на другие объекты файловой системы.

**2. Объясните назначение связей с файлами и способы их создания.**
Связи (ссылки) используются для доступа к одному файлу или его данным через разные имена или из разных мест.
*   **Жесткая ссылка** (`ln file1 link1`) — ещё одно имя для тех же самых данных (inode). Нельзя создать для директории или на другой раздел. При удалении оригинала данные остаются доступными по ссылке.
*   **Символическая ссылка** (`ln -s file1 symlink1`) — отдельный файл-указатель, содержащий путь к цели. Аналог «ярлыка» в Windows. Можно ссылаться на директории и другие разделы. При удалении оригинала ссылка становится нерабочей.

**3. Что определяет атрибуты файлов и каким образом их можно просмотреть и изменить?**
Атрибуты определяют права доступа к файлу (чтение, запись, выполнение для владельца, группы и остальных), информацию о владельце, группе, размере, времени модификации.
*   **Просмотр:** `ls -l` (базовые права и метаданные), `stat` (подробная информация), `lsattr` (расширенные атрибуты, например, неизменяемость).
*   **Изменение:** `chmod` (изменение прав доступа), `chown` (смена владельца), `chgrp` (смена группы), `touch` (изменение времени), `chattr` (установка расширенных атрибутов).

**4. Какие методы создания и удаления файлов, каталогов Вы знаете?**
*   **Создание файлов:** `touch` (создать пустой), `echo/cat > file` (через перенаправление ввода), текстовые редакторы (`nano`, `vim`).
*   **Удаление файлов:** `rm` (удаление файла, с ключом `-f` принудительно, с `-i` запрос подтверждения).
*   **Создание каталогов:** `mkdir` (создать директорию, `-p` для создания цепочки вложенных папок).
*   **Удаление каталогов:** `rmdir` (удалить пустую директорию), `rm -r` (рекурсивное удаление со всем содержимым).

**5. В чем заключается поиск по шаблону?**
Поиск по шаблону (glob-паттерны) позволяет выбирать файлы, чьи имена соответствуют определённой маске, без перечисления полных имён. Основные символы подстановки:
*   `*` — любое количество символов (включая ноль).
*   `?` — ровно один любой символ.
*   `[...]` — любой один символ из указанного диапазона (например, `[a-z]`).
*Пример:* Команда `ls *.txt` выведет список всех файлов в текущем каталоге с расширением `.txt`.

**6. Какой командой можно получить список работающих пользователей и сохранить его в файле?**
Чтобы получить список пользователей, работающих в системе в данный момент, и сохранить его в файл, нужно использовать перенаправление вывода:
```bash
who > users_list.txt
```
или
```bash
w > users_active.txt
```
Команда `who` показывает имя пользователя, терминал и время входа. Символ `>` записывает вывод команды в файл (если файла нет, он создаётся; если есть — перезаписывается). Для добавления в конец файла используется `>>`.
